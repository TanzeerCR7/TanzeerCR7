## Featured project

### StayIQ: Hotel Booking Revenue & Cancellation Intelligence
Analysed 119,390 real hotel bookings to measure how much revenue is exposed to cancellations and which segments drive it.

- **37.04%** overall cancellation rate; City Hotel 41.73% vs Resort Hotel 27.76%
- **16.73M** revenue exposure from cancelled bookings (nightly rate × length of stay)
- Transient customers bring about **74%** of realised revenue
- Built with SQL (SQLite), Python/pandas, an interactive Power BI dashboard with DAX measures, and a metric-definitions table in the README

[View the repository](https://github.com/TanzeerCR7/stayiq-hotel-analytics)

**What I learned:** a peer review showed my first headline figure used the wrong calculation. I rebuilt the metric, updated the SQL, DAX, dashboard and README, and documented the change. Details are in the repo.
